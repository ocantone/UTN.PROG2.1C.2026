# UTN.PROG2.1C.2026
Repositorio de Programación II en TUP UTN FRH 1er Cuat 2026 Pablo Gambacorta, O. Cantone
Aquí encontrarán algunos ejemplos de código utilizados en clase. Están ordenados por temas:

* Listas
    * 📂 Lista Alumnos: Ejemplo de manejo de una Lista de objetos 'class Alumnos'.
    * 📂 Lista Materias: Ejemplo de manejo de una Lista de strings.
* Colas
    * 📂 Queue Lavadero Autos: Aplicación de consola que utiliza colas (queue) para registrar autos en un lavadero.
* Pilas
    * 📁 Stack Libros: App que registra el ingreso de libros en una estructura tipo pila (Stack).
* Persistencia en Archivos
    * 📁 Lista Alumnos JSON: Agrega persistencia en un archivo JSON al ejemplo Lista Alumnos.
    * 📁 LavaderoAutosTXT: Agrega al ejemplo del lavadero de autos persistencia en un archivo .txt
    * 📁 Lavadero Autos JSON: Agrega al ejemplo de cola de autos del lavadero persistencia en un archivo JSON.
* Persistencia en Base de Datos
    * 📁 ListaBDAlumnos: Aplicación básica de conexión con un servidor de base de datos MySql que muestra por pantalla el contenido de una tabla.
    * 📁 ListaBDMVC: Esta aplicación hace lo mismo que ListaBDAlumnos, pero inplementando el modelo MVC.
    * 📁 AdminAlumnos: Implementa CRUD (Create, Read, Update, Delete), las cuatro operaciones básicas en una tabla mediante consultas SQL.
